# Web Registro Socios

Proyecto realizado con:

* Spring Web
* Thymeleaf

Ejecución:

```
# ejecución en Linux o Mac
./gradlew bootRun

# Ejecución en Windows
.\gradlew.bat bootRun
```



## Cambio puerto

Si necesita cambiar el puerto lo puede hacer editando el archivo **_application.properties_**:

```
server.port=9050
```
